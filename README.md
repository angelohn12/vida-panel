# vida-panel

Dashboard personal privado de Anyelo Hidalgo. Protegido por Cloudflare Access — sin login autorizado no responde.

Este repo es público. No contiene datos, credenciales, ni endpoints operativos.

## Stack

- Frontend: HTML/CSS/JS vanilla, un solo archivo (`index.html`).
- Backend: Google Sheets + Apps Script (fuera de este repo).
- Hosting: Cloudflare Pages.
- Autenticación: Cloudflare Access (OTP por email).
- PWA: acceso desde pantalla de inicio en iPhone/Android.
